# Radiology v2 — قسم الأشعة (عربي / English)

ملف واحد جاهز: `index.html`. الموقع القديم (`mhmradiology`) ما تغيّر ويبقى شغال.

## النشر
1. أنشئ مستودع GitHub **Private** باسم `radiology-v2` وارفع `index.html` و`README.md`.
2. Netlify ← Add new project ← Import from Git ← اختر المستودع. Build command فارغ وPublish directory = `/`.
3. لجعل الموقع خاصًا: Netlify ← Project configuration ← Access & security ← Visitor access (قد يتطلب خطة مدفوعة).

## الدخول
نفس الرقم الوظيفي وكلمة المرور الحالية. الموظف الجديد يضغط "طلب حساب جديد" ثم يقبله الأدمن ويسلّمه كلمة مؤقتة.
